# Mensajes al Mar

Juego de intercambio de regalos de Navidad: cada día llega una botella con una pista.

- Versión real: https://jazzybluezz.github.io/mensajes-al-mar/
- Versión de prueba: https://jazzybluezz.github.io/mensajes-al-mar/prueba/

Los datos (pistas, fotos, respuestas) viven en Supabase, protegidos por reglas de acceso.
Este repositorio solo tiene el código de la página.
